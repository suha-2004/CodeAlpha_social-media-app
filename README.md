# 🚀 SocialApp

A modern full-stack social media web application built using HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, and JWT Authentication.

Users can create posts, upload images, like posts, comment, reply to comments, and interact with a clean social media feed interface.

# ⚙️ Installation

## 1️⃣ Clone Repository

git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git

---

## 2️⃣ Install Backend Dependencies

cd backend

npm install

---

## 3️⃣ Start Backend Server

npm start

or

nodemon server.js

---

## 4️⃣ Open Frontend

Open `feed.html` in browser.

---

# 🌐 MongoDB Setup

1. Create MongoDB Atlas account
2. Create Cluster
3. Connect using connection string
4. Add your MongoDB URI inside backend server configuration

---

# 🔑 Environment Variables

Create `.env` file inside backend folder:

PORT=5000

MONGO_URI=YOUR_MONGODB_CONNECTION

JWT_SECRET=YOUR_SECRET_KEY
